# 信耶稣 · 属灵成长合集 — 总纲与目录

## 这套合集是给谁的、怎么用

这套合集是为慕道友和初信者预备的一条属灵成长路径。你不需要有任何教会背景，也不需要先读懂整本圣经——只要你愿意认识耶稣、想知道信了之后的日子该怎么走，就可以从第一站开始，顺着走下去。

全程共八站，像爬楼梯一样，一站比一站深：

- **不要跳站。** 每一站都是下一站的地基。先把"信的是谁、信了得着什么"弄清楚，再谈门徒生活；先学会听神的声音，才谈得上跟随祂的带领。
- **可以自学，也可以找人陪读。** 一个人读没有问题；若有信主多年的弟兄姊妹陪你一站一站走，收获会更扎实。每一站都给了学习顺序和现成的网上资源，手机上就能学。
- **每一站慢慢来。** 一站停留几周很正常。读经文、做操练、在生活中试着活出来，比赶进度重要得多。

站与站之间也有内在的次序：先有**主线**（认识耶稣、信主入门），才谈**门徒**（跟随祂过日子）；听**懂神的声音**，才能**跟随神的带领**；认识**圣灵**，才进到**异象异梦**这些较深的经历；**坚持到底**是前面一切在苦难中的检验；最后落到**家族**——信仰不是一个人的事，要带进婚姻、亲子和整个家。

## 第一站 · 主线——认识耶稣、信主入门

### 这一站讲什么

这是整条路的起点，先回答三个最基本的问题：耶稣是谁？祂为我们做了什么？我怎么才能与祂建立关系？这一站把福音讲清楚：神爱世人，人因罪与神隔绝，耶稣基督为我们的罪死在十字架上、第三天复活，人只要认罪悔改、接受耶稣作救主和生命的主，就得着赦免和永生。同时要把基要真理打牢——得救的确据不是靠感觉，而是靠神在圣经里的应许。走完这一站，你应该能用自己的话把福音讲给别人听，也能确知自己是神的儿女。

### 经文根基

- 约翰福音 3:16——神爱世人，赐下独生子，信祂的人得永生
- 罗马书 3:23；5:8——人人都犯了罪，基督在我们还作罪人的时候为我们死
- 以弗所书 2:8-9——得救本乎恩、因着信，不是出于行为
- 罗马书 10:9-10——口里承认、心里相信，就必得救
- 约翰一书 5:13——信的人可以**知道**自己有永生

### 推荐学习顺序

1. 先读四福音中一卷，建议从马可福音或约翰福音开始，认识耶稣这个人。
2. 用《四个属灵的定律》把福音的四条骨干理一遍；若已决志，照着里面的带领再确认一次自己的得救。
3. 想系统地问、慢慢地想，参加一期启发课程（Alpha），十周左右把大问题问透。
4. 每天花十几分钟看 BibleProject 的短视频，帮自己把圣经的大故事串起来。

## 第二站 · 门徒——门徒训练

### 这一站讲什么

信主是起点，不是终点。耶稣的吩咐不是"使人信教"，而是"使万民作我的门徒"。这一站学的是怎样过门徒生活：自己读经、自己祷告、在教会里团契与服事、向人作见证，并且进一步去陪伴、栽培比你更新的信徒。重点是把第一站的道理变成每天的习惯——门徒不是多知道些什么，而是多像耶稣一点，并且能把所学的传给下一个人。

### 经文根基

- 马太福音 28:19-20——大使命：使人作门徒，教训他们遵守主所吩咐的
- 路加福音 9:23——天天背起十字架来跟从主
- 约翰福音 15:5、8——住在主里面，多结果子，就是主的门徒
- 提摩太后书 2:2——把所听见的交托忠心能教导别人的人

### 推荐学习顺序

1. 先建立两个习惯：每天读经（从马可福音、一卷一卷往下读）和祷告，各十几分钟即可，贵在持续。
2. 用导航会《在基督里成长》系列走完 13 周，把得救确据、祷告、胜过罪、参与教会这些基本功逐个打牢。
3. 用《初信栽培》课程补上系统的栽培课，特别适合刚受洗不久的人。
4. 每天用《灵命日粮》作灵修的固定节奏，养成天天亲近神的生活。

## 第三站 · 听懂神的声音

### 这一站讲什么

神今天仍然向祂的儿女说话。问题通常不是神不说，而是我们不熟悉祂的声音，或者生活太吵，听不见。这一站学辨认神说话的途径：主要透过圣经，也透过祷告中的感动、环境的安排、教会的印证和圣灵在里面的提醒。同时要立一条界线：神绝不会说与圣经相违背的话；凡与圣经冲突的"声音"，不管多强烈，都不是出于神。学完这一站，你该能安静下来，分辨哪些是神在对你说话，并知道怎样回应。

### 经文根基

- 约翰福音 10:27——我的羊听我的声音，我也认识他们，他们也跟着我
- 撒母耳记上 3:9-10——小撒母耳学听神说话："请说，仆人敬听"
- 诗篇 46:10——你们要休息（安静），要知道我是神
- 以赛亚书 30:21——你或向左或向右，必听见后边有声音说：这是正路
- 约翰福音 16:13——真理的圣灵引导我们明白一切的真理

### 推荐学习顺序

1. 先从约翰福音 10 章读起，再读撒母耳记上 3 章，看圣经里的人怎样听、怎样回应。
2. 操练安静：每天留一段不看手机的时间，读一小段经文，祷告，把心里的感动记下来，事后再用圣经印证。
3. 系统学习走《经历神》课程，尤其其中"神说话"和"信心的危机"两部分。
4. 听黑布亨利的讲道录音，补上牧者第一手的经验分享。

### 网上资源

## 第四站 · 跟随神的带领

### 这一站讲什么

听得见，还要跟得上。这一站处理实际的抉择：换不换工作、跟谁结婚、搬不搬家、要不要出来服事。圣经给的原则很实际：神的旨意先写在圣经里——圣经已经说清楚的事，不必再问；圣经没写明的具体抉择，则用祷告求智慧、看里面的平安、查环境的开路、听成熟信徒和教会的劝告，几方面对得上，再凭信心走出去。还要防两个极端：一是把每个巧合都当神迹，二是迟迟不敢行动、把"等候"当借口。神带领愿意行动的人，像祂带领亚伯拉罕一样，走一步，亮一步。

### 经文根基

- 箴言 3:5-6——专心仰赖耶和华，祂必指引你的路
- 诗篇 32:8——我要教导你，指示你当行的路
- 罗马书 12:1-2——心意更新而变化，察验何为神善良、纯全、可喜悦的旨意
- 雅各书 1:5——缺少智慧的，应当求那厚赐与众人的神
- 使徒行传 16:6-10——保罗被圣灵禁止、又得马其顿呼声的异象，带领有开门也有关门

### 推荐学习顺序

1. 先读罗马书 12 章和箴言 3 章，把"旨意"的根基打在顺服与信靠上，而不是找捷径。
2. 读《神的旨意》一篇，学会用圣经、里面引导、环境三者互相印证的方法。
3. 正面对抉择时，用 McDowell 的文章逐项自问：圣经怎么说？我祷告了吗？我问过成熟的人吗？
4. 回到《经历神》的功课：看神已经在哪里作工，调整自己的计划去配合祂，而不是求祂配合你。

## 第五站 · 圣灵——认识圣灵、圣灵的充满与恩赐

### 这一站讲什么

圣灵不是一种气氛或能力，祂是三位一体中的一位，是主耶稣升天后赐给教会的保惠师。这一站分三层学：先认识圣灵是谁、祂作什么（重生、内住、引导、安慰、责备）；再学圣灵的充满——不是一次得着就够了的经历，而是天天顺服、被祂管理的生活状态，其证据是加拉太书所说的果子；最后认识属灵的恩赐：圣灵随己意分给各人，目的不是炫耀，而是建立教会、服事人。次序要紧：先追求果子，再谈恩赐；先被圣灵管理，再求祂的能力。

### 经文根基

- 使徒行传 1:8——圣灵降临在你们身上，你们就必得着能力，作主的见证
- 使徒行传 2:38-39——悔改受洗、罪得赦免，就必领受所赐的圣灵；这应许是给一切信的人
- 以弗所书 5:18——不要醉酒，要被圣灵充满
- 加拉太书 5:22-23——圣灵所结的果子：仁爱、喜乐、和平、忍耐、恩慈、良善、信实、温柔、节制
- 哥林多前书 12:4-11——恩赐原有分别，圣灵却是一位，随己意分给各人，为要叫人得益处

### 推荐学习顺序

1. 通读一遍使徒行传，留意圣灵在初代教会怎样工作。
2. 用门训课《追求圣灵充满》打底，弄清"内住"与"充满"的区别。
3. 小组一起查哥林多前书 12-14 章，认识恩赐的种类与使用的原则（爱与次序）。
4. 查加拉太书 5 章，把焦点放回果子：先求生命改变，再求事奉能力。

## 第六站 · 异象异梦

### 这一站讲什么

圣经里，神多次用异象和异梦向人说话：向约瑟、向但以理、向彼得，也向保罗。使徒行传 2 章应许，末后的日子圣灵浇灌下来，少年人要见异象，老年人要做异梦。这一站先把圣经基础打稳：异象异梦是神说话的方式之一，但不是唯一，也不是最高——一切领受都要回到圣经检验，凡与圣经真理冲突的，一概不取。再学操练：祷告中领受、忠实地记录、求圣灵解释、寻求印证，并在教会和成熟领袖的遮盖下分享，不自作主张、不拿异象异梦辖制人。态度对了，异象异梦是祝福；次序乱了，反成混乱。这也是中文世界里材料最少的一站，更要回到圣经本身慢慢学。

### 经文根基

- 使徒行传 2:17——末后的日子，少年人要见异象，老年人要做异梦（引约珥书 2:28）
- 约伯记 33:14-18——神在梦中、夜间异象中，开通人的耳朵，将教训印在人心
- 但以理书 2:19-23——但以理在夜间异象中得奥秘，称颂那显明深奥隐秘事的神
- 约翰一书 4:1——一切的灵不可都信，总要试验那些灵是出于神的不是

### 推荐学习顺序

1. 先读圣经原文：创世记 37-41 章（约瑟的梦与解梦）、但以理书 2 章、使徒行传 10 章（彼得的异象）和 16 章。
2. 用生命河灵粮堂《异象与异梦》课程讲义系统学一遍：应许、解释、辨别、操练，四部分按次序走。
3. 开始操练：睡前祷告，把梦和异象记下来，第二天祷告求解释，并求经文印证；先记录，不急着下结论。
4. 找成熟的属灵长辈或牧者分享你的领受，在遮盖下学习分辨。

## 第七站 · 坚持到底——苦难、试炼与坚忍

### 这一站讲什么

信主不等于从此无风无浪。主耶稣明说：在世上你们有苦难。疾病、失业、亲人离世、祷告久久不应允，都会临到敬虔的人。这一站要把苦难想明白：苦难不是神不在，也不是你信心不够——试炼显明信心的真假，也炼净信心，像火炼金子。圣经的应许不是"免去苦难"，而是神必与我们同在、不叫我们受试探过于所能受的，并且在这一切事上靠着爱我们的主得胜有余。这一站也学实际的功课：怎样在等候中不灰心，怎样陪伴受苦的人（少讲道理，多在场），怎样回头看神一路的信实。

### 经文根基

- 雅各书 1:2-4、12——落在百般试炼中要以为大喜乐，忍耐成功，承受试炼的人得生命的冠冕
- 彼得前书 1:6-7——信心的试验比能坏的金子更显宝贵
- 罗马书 5:3-5——患难生忍耐，忍耐生老练，老练生盼望，盼望不至于羞耻
- 哥林多前书 10:13——神是信实的，必不叫你们受试探过于所能受的，总要开一条出路
- 希伯来书 12:1-2——存心忍耐，奔那摆在前头的路程，仰望为我们信心创始成终的耶稣

### 推荐学习顺序

1. 先读约伯记（可先读 1-2 章、38-42 章）和诗篇 42、73 篇，看圣经里的人怎样在苦难中向神说话。
2. 查雅各书 1 章和彼得前书 1 章，把试炼的目的和态度学透。
3. 在低谷的日子里，每天用《灵命日粮》托住自己，一天一天地过。
4. 进深阅读凯勒《行经苦难》，把"为什么"这个问题想完整。

## 第八站 · 家族——家庭祭坛、婚姻亲子、家族的祝福

### 这一站讲什么

信仰走到最后，要落在一个"家"字上。申命记吩咐以色列人：要把神的话教训儿女，无论坐在家里、行在路上、躺下、起来，都要谈论。这一站学三件事：一是建立家庭祭坛——固定时间，全家一起读一点经、唱一首诗、彼此代祷，从十分钟开始，重在持续；二是婚姻与亲子按圣经经营：丈夫像基督爱教会一样爱妻子，父母在主里教养儿女、不惹儿女的气；三是眼光放长：信仰要传给儿女、儿女的儿女，一个家的祝福可以存到千代。约书亚的话是这一站的总结："至于我和我家，我们必定事奉耶和华。"

### 经文根基

- 申命记 6:4-7——要尽心爱主，并殷勤教训儿女，在家里、路上、躺下、起来都要谈论
- 约书亚记 24:15——至于我和我家，我们必定事奉耶和华
- 创世记 18:19——神拣选亚伯拉罕，为要吩咐他的众子和后代遵守主的道
- 以弗所书 5:25；6:4——丈夫要为妻子舍己；父亲不要惹儿女的气，要照主的教训养育他们
- 诗篇 78:4-7——将耶和华的美德和祂所行的奇事述说给后代听，使他们仰望神

### 推荐学习顺序

1. 先读申命记 6 章和诗篇 78 篇，明白"家"在神计划里的位置。
2. 从小处开始家庭祭坛：每周一次、十分钟，读经、分享、代祷三件事，照《家庭祭坛 101》的细则排时间、定地点、分主责。
3. 夫妻一起查以弗所书 5-6 章，再用婚姻课程逐课经营夫妻关系。
4. 有孩子的，用《我和我家》小组课程把基督教的家庭观和亲子课题一课一课学。
